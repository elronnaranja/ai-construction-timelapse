# Start here — Codex or Claude

Give either agent this instruction, with access to this folder:

> Read WORKFLOW.md and the project's manifest.json. Create or resume the six-stage construction transformation. Keep natural construction sounds; exclude background music, singing, narration and dialogue. Lock the final storey count and roof height throughout every image and clip; never build an extra floor and remove it later. Check intermediate video frames, not only endpoints. Design the completed house first, preserve the specified surroundings, and end on the fully finished property. Discard Flow audio. Prepare separate music-free scene-effect tracks, listen to them, and record a hash-bound audio review before assembling with assemble.py. Stop if listening approval is unavailable. Use only the selected Flow account and authorized existing credits; no purchases. Keep every Flow SOUND instruction in ALL CAPS and prohibit static, buzzing and distortion as well as music. Export the actual final MP4 and embed/attach it in the final chat with its download link; an HTML preview is not final delivery. Reuse completed jobs and report unavailable tools or quality failures.

For a new project, describe the idea. Defaults are portrait 9:16, six images, five transitions at 10 Flow credits each, a 50-existing-credit cap and no purchases. Starting a video authorizes this standard run; no repeated credit or hero-image approval is needed. Infer omitted creative details. Save all prompts first and fill/paste each in one operation. Stop only for real blockers, required new legal consent or unavailable listening review.

Files:
- `WORKFLOW.md`: the complete operating instructions.
- `assemble.py`: assembly using only separate, reviewed scene effects; Flow audio is excluded.
- `preferences.json`: saved user defaults.
- `archive/assemble_silent.py`: historical script only; use solely when silence is explicitly requested.

Each agent needs its own image backend, authenticated browser tools and file access. Copy the project images, clips and manifest when handing off. Do not copy credentials. Historical project prompts and videos describe their original runs; they are not the current default instructions.
