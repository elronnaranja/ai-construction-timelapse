# Start here — Codex or Claude

Give either agent this instruction, with access to this folder:

> Read WORKFLOW.md and the project's manifest.json. Create or resume the six-stage construction transformation. Before generating images or spending credits, follow BROWSER-SETUP.md and verify working Flow browser control, login and supported transfers. Guide one-time setup clicks if needed; do not treat full access as a browser connection. Keep natural construction sounds; exclude background music, singing, narration and dialogue. Lock the final storey count and roof height throughout every image and clip; never build an extra floor and remove it later. Check intermediate video frames, not only endpoints. Design the completed house first, preserve the specified surroundings, and end on the fully finished property. Discard Flow audio. Prepare separate scene-matched construction effects from owned or appropriately licensed isolated SFX, record their sources, and combine automatically using assemble.py. No listening approval or review JSON is required. Use only the selected Flow account and authorized existing credits; no purchases. Keep every Flow SOUND instruction in ALL CAPS and prohibit static, buzzing and distortion as well as music. Export the actual final MP4 and embed/attach it in the final chat with its download link; an HTML preview is not final delivery. Reuse completed jobs and report unavailable tools or quality failures.

For a new project, describe the idea. Defaults are portrait 9:16, six images, five transitions at 10 Flow credits each, a 50-existing-credit cap and no purchases. Starting a video authorizes this standard run; no repeated credit or hero-image approval is needed. Always ask the initial questions in AGENTS.md for a new video and wait for answers; summarize supplied details and ask what is missing, or confirm a complete brief once. Each new video uses fresh creative answers, not answers from earlier videos. The initial questionnaire is the only planned typed input; handle the rest automatically and request concise approval only for genuinely new requirements or blockers. Explicit resume requests use the same project manifest. Save all prompts first and fill/paste each in one operation. Stop only for real blockers, required new legal consent or technical failures.

Files:
- `WORKFLOW.md`: the complete operating instructions.
- `assemble.py`: assembly using only separate scene effects; Flow audio is excluded.
- `preferences.json`: saved user defaults.
- `archive/assemble_silent.py`: historical script only; use solely when silence is explicitly requested.

Each agent needs its own image backend, authenticated browser tools and file access. Copy the project images, clips and manifest when handing off. Do not copy credentials. Historical project prompts and videos describe their original runs; they are not the current default instructions.
